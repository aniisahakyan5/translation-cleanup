Translation Key Reconciler
Per-application comparison of code usage against database and dictionary sources
Inputs Drop your CSV files anywhere on this panel — they are matched by name and columns
Keys: on each repo switch to main, then Code → Download ZIP and drop the .zip — or the folder it expanded into — onto this panel. Safari expands downloads automatically, so dragging the front-main folder works just as well. Archives cut from any other branch — or from another repository — are refused by the front-main/mobile-main/app-main wrapper name, and the commit read is shown once the keys land. Read in your browser, no token needed. (A plain key list still works too.)
DB sources: pick an application above, copy the query, run it, and drop the result in. Only the applications you supply are reconciled, and their dictionary rows are dropped automatically.
Dictionary: a separate export from public.dictionary including the source column — the key query cannot provide it, and source missing and source mismatch are measured against it.
